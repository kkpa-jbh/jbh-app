# Internationalization (i18n)

## Critical Rule
**NEVER hardcode user-facing text. ALWAYS use the translate pipe.**

## Translation Files
Location: `src/assets/i18n/`
- `en.json` - English
- `es.json` - Spanish

### Structure
```json
{
  "common": {
    "cancel": "Cancel",
    "delete": "Delete",
    "save": "Save"
  },
  "featureName": {
    "errors": {
      "generic": "An error occurred"
    },
    "fieldName": {
      "label": "Field Label",
      "minlength": "Must be at least {{minLength}} characters",
      "placeholder": "Enter value",
      "required": "Field is required"
    },
    "subtitle": "Feature subtitle",
    "title": "Feature Title"
  }
}
```

**Rules:**
- Sort keys alphabetically (top-level and within groups)
- Don't repeat translations - use `common` namespace
- Use parameters for dynamic values: `{{param}}`

## Component Implementation

```typescript
import { TranslateModule } from '@ngx-translate/core';
import { TranslationService } from '@core/infrastructure/i18n/translation.service';

@Component({
  standalone: true,
  imports: [IonicModule, TranslateModule]  // Always include!
})
export class ExamplePage {
  constructor(public translationService: TranslationService) {}

  getMessage(): string {
    return this.translationService.instant('feature.message', { param: 'value' });
  }
}
```

## Template Usage

```html
<!-- Static text -->
<ion-title>{{ 'feature.title' | translate }}</ion-title>

<!-- With parameters -->
<p>{{ 'feature.welcome' | translate:{ name: userName } }}</p>

<!-- Form labels -->
<label>{{ 'feature.field.label' | translate }}</label>
<ion-input [placeholder]="'feature.field.placeholder' | translate">

<!-- Buttons -->
<ion-button>{{ 'common.save' | translate }}</ion-button>
```

## Programmatic Translation

```typescript
// Synchronous (when translations loaded)
const msg = this.translationService.instant('feature.message');
const msgWithParams = this.translationService.instant('feature.greeting', { name: 'John' });

// Observable (for dynamic)
this.translationService.get('feature.message').subscribe(t => console.log(t));
```

## Language Switching

```typescript
// Set language
this.translationService.setLanguage('es');

// Toggle
this.translationService.toggleLanguage();

// Get current
const lang = this.translationService.getCurrentLanguage();

// Available
const languages = this.translationService.availableLanguages;
// [{ code: 'en', name: 'English' }, { code: 'es', name: 'Español' }]
```

## Key Naming Convention
```
[feature].[component].[element].[property]

Examples:
- login.title
- login.username.label
- login.username.placeholder
- login.username.required
- login.errors.invalidCredentials
- common.save
- validation.required
```

## Form Validation Messages

```typescript
getErrorMessage(fieldName: string): string {
  const field = this.form.get(fieldName);
  if (!field?.errors) return '';

  if (field.hasError('required')) {
    return this.translationService.instant(`feature.${fieldName}.required`);
  }
  if (field.hasError('minlength')) {
    const minLength = field.errors['minlength'].requiredLength;
    return this.translationService.instant(`feature.${fieldName}.minlength`, { minLength });
  }
  return this.translationService.instant('validation.pattern');
}
```
